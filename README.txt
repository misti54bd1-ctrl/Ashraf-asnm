Ashraf.ASNM — Offline personal accounts PWA

Files:
- index.html: app
- manifest.json: install metadata
- sw.js: offline cache service worker
- icon.svg: app icon

INSTALLATION NOTE:
For Android Chrome installation, upload this folder to a static HTTPS host (for example GitHub Pages). Open the HTTPS URL in Chrome, then menu > Install app / Add to Home screen. After the first visit and install, app files are cached for offline use.

Account data is stored locally in the browser. Export backups regularly. PIN lock is not encryption.
